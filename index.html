CONFIGURAÇÕES

Seu acompanhamento

Corrigir essa data não apaga registros já feitos.

Trocar de ciclo

Quando começar uma nova sessão, inicie outro ciclo. Os anteriores permanecem no histórico deste navegador.

Foto da capa

Coloque sua fotografia no arquivo assets/ana-luiza.jpg do site e publique no GitHub Pages. A capa mostrará a foto automaticamente.

Segurança dos dados e backup

Os registros persistem neste mesmo navegador/dispositivo, mas não sincronizam entre celulares. Limpar dados do navegador pode apagá-los. Exporte um backup periodicamente.

Atenção: o GitHub Pages hospeda uma página acessível pela web. A foto e a rotina escrita nos arquivos do site podem ser vistas por quem acessar o endereço. Os registros feitos na página permanecem no dispositivo, salvo quando exportados manualmente.
